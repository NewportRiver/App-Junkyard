# App Junkyard — Start Here

**Repository:** https://github.com/NewportRiver/App-Junkyard

The private GitHub repository now contains the initial concept and HTML-first development plan. This is a planning baseline; no software marketplace or live payment processing has been deployed.

1. Read README.md and docs/CONCEPT.md.
2. Review docs/DEVELOPMENT_PLAN.md and docs/MVP_PLAN.md.
3. Confirm rights, licensing and safe handling in docs/RIGHTS_AND_SECURITY.md.
4. Use FEATURES.md to prioritize the first sprint.
5. Implement on feature branches and require review before merging.

## First milestone

Build a responsive static HTML/CSS/TypeScript storefront driven by fictitious demonstration listings, with obvious demo labeling and no transactions. Record test results and known bugs before continuing to authenticated inventory intake.
